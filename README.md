# GLIDE90

A reverse gate and vibrato-bar glide audio plugin: VST3 and standalone on Windows, macOS and Linux,
plus AU on macOS and LV2 on Linux.

Builds are on the [releases page](../../releases). Each zip has an `INSTALL.txt`.
